# NFT Casino Mini-App

Мини-приложение для Telegram с рулеткой, кейсами и коллекционными NFT-подарками (виртуальные копии коллекций Telegram).

## Как запустить

1. Создай репозиторий на GitHub и загрузи туда эти файлы.
2. В настройках репозитория (Settings → Pages) включи GitHub Pages: Source → Deploy from a branch → main.
3. Дождись зелёной галочки «Your site is live» (может занять 1–2 минуты).
4. Получи ссылку вида `https://твой_ник.github.io/репозиторий/`.
5. Вставь эту ссылку в кнопку Web App бота (через BotFather или код бота).

## Особенности

- **Рулетка** с разными ставками и выплатами.
- **Кейсы** (бронзовый, серебряный, золотой, легендарный) с разной вероятностью выпадения.
- **Апгрейд** NFT с риском потерять предмет.
- **Передача** NFT между игроками через код-квитанцию.
- **Продажа** NFT за 70% стоимости.
- **Закрепление** и **статус** из инвентаря.
- Данные хранятся в `localStorage` (без сервера).

## Важное предупреждение

Это **игровая симуляция**. NFT-подарки — виртуальные копии коллекций Telegram. Настоящие NFT продаются на Fragment за реальные деньги. Проект не связан с Telegram и не является финансовым сервисом.
